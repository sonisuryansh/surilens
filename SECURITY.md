# Security Policy

## Supported Versions

SuriLens actively maintains and patches security vulnerabilities for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a security vulnerability within SuriLens, please **do not open a public issue**. Instead, send an email directly to the maintainer:

📧 **Maintainer**: Suryansh Soni ([https://github.com/sonisuryansh](https://github.com/sonisuryansh))

Please include:
1. A description of the vulnerability and its potential impact.
2. Step-by-step instructions or a minimal proof-of-concept to reproduce the issue.
3. Any proposed remediations if available.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to release a security patch promptly.
