# 🤝 Contributing to SuriLens

Thank you for considering contributing to SuriLens!

---

## Development Workflow

1. Fork and clone repository.
2. Install dependencies: `npm install`.
3. Start local demo application: `npm run demo`.
4. Run syntax verification: `npm test`.

## Code Guidelines

- Maintain **Zero Heavy Mandatory Dependencies** in `package.json`.
- Ensure all new public API additions are backward-compatible.
- Run `node --check index.js` before submitting pull requests.
